# Gaius Obimba — Engineering Portfolio

Responsive static website built with HTML and CSS.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `gaius-obimba-portfolio`.
2. Upload `index.html` and `styles.css` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Use the URL GitHub provides.

## Before publishing
- Verify all statements and dates.
- Replace the CSS illustrations with your own approved project photos, Altium screenshots, and diagrams.
- Add a resume PDF if desired.
- Confirm contact details and LinkedIn URL.
- Get team approval before publishing schematics, board files, or confidential design information.

Project text intentionally distinguishes ongoing work from completed fabrication, assembly, and board testing.
